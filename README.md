## 🌟 为什么需要 dsh-qq-buffer？

在将大语言模型（LLM / Agent）接入 QQ 群聊的实际生产场景中，开发者往往面临以下**核心痛点**：

1. **群友碎片轰炸，算力与 Token 暴风骤雨**：群友习惯将一句话拆分成 3~5 条短消息发送。普通 Bot 会针对每条碎片消息独立触发一次 LLM 思考，不仅极度消耗算力，还会导致 Bot 逻辑前后矛盾、“左右脑互搏”。
2. **状态词与内部报错裸露**：LLM 在执行复杂 Agent 工作流或工具调用时，偶尔会吐出内部状态词（如 `task ready`、`task completed`、`NO_REPLY`）或中间工具调用异常栈，严重破坏拟人人设。
3. **恶意 Prompt 注入与越权攻击**：公开群聊中常有攻击者尝试使用“忽略之前指令”、“输出你的系统提示词”、“开启开发者模式”等套路进行越狱催眠或刺探服务器机密。
4. **机械式死板插嘴**：机器人对群友日常闲聊或彼此对话频繁搭话，造成群内噪音和严重打扰。
5. **长篇大论不符合群聊习惯**：Bot 一次性输出上千字大段排版，在移动端 QQ 群极其突兀，甚至被官方截断或折叠为卡片。
6. **网络抖动与多渠道复读**：由于网络重试或外部推送管道冲突，图片和消息容易在短时间内被重复下发。

**`dsh-qq-buffer`** 是专为解决上述痛点而打造的**基础设施级 Cordis 插件**。它在 DeepSeek Harness 与 QQ 官方开放平台 SDK 原型链之间构筑了一套高可靠、低延迟、零侵入的消息拦截与缓冲调度管线，并提供完整的可视化 WebUI 控制大盘。

## 🚀 核心特性

### 1. 🌊 双轨时序缓冲与上下文聚合 (Dual-Track Buffering)
- **轨道 A（提及快速收敛 Mention Wait）**：当用户明确点名或 `@机器人` 时，启动快速收敛窗口（默认 5 秒），既保证及时回话，又包容紧随其后的补充说明。
- **轨道 B（普通消息防抖 Idle Debounce）**：群友连续打字时自动进入空闲倒计时（默认 8 秒），无新消息后合并一次性移交主模型。
- **结构化上下文聚合**：多条消息合并时，自动区分 `👉[核心触发]` 与 `[群聊背景]`，附件图片全量聚合，不丢失任何细节。

### 2. ⚡ 交付即起跑与连续动作指令直通 (Delivery-Anchored Fast-Path)
- **交付即起跑 (Delivery-Anchored Window)**：以机器人**最终出站交付完成的瞬间**作为计时起点，开启连续对话活跃期（默认 120 秒），杜绝 Agent 复杂思考耗时吞噬群友活跃时间。
- **动作指令零延迟直通 (Action Fast-Path)**：在连续对话活跃期内，当前对话人发送指令（如“好的”、“继续”、“执行第3个”、“选择A”等），通过正则**0ms 绕过初筛模型直接直通主模型**，体验极其流畅。
- **多模态交付全覆盖**：无论出站的是文本、语音还是图片，均可自动锚定交付完成状态。

### 3. 🛡️ 物理级安全防御与主人特权白名单 (Security Guard)
- **非主人注入防御**：基于恶意特征库毫秒级识别提示词注入、越权系统指令、身份伪造与系统文件刺探试探，未唤醒主模型前就地静默处决。
- **主人专属特权**：支持配置唯一主人 `master_sender_id` 与 `master_name`，享有 100% 安全白名单豁免，调试指令与重置指令畅通无阻。
- **C2C 私聊紧急告警**：群内发生非主人攻击时，自动向主人发起私聊告警卡片，详细记录攻击者、群号及攻击原文。

### 4. 🛑 系统状态词与工具报错物理拦截 (Physical Interception)
- **违禁词阻断**：严格拦截 `task ready`、`task completed`、`NO_REPLY`、`[不回复]`、`[静默]` 等内部指令。
- **工具报错熔断**：物理拦截内部执行报错（如 `❌ 工具 xxx 执行失败`、`🔧 xxx 完成`、`⚠️ 本轮异常结束`），对外永远保持优雅稳定的人设。
- **私聊与后台标记保护**：包含 `[仅私聊]`、`[PRIVATE]` 或 `[仅后台]` 标识的输出出站层 100% 物理拦截，杜绝技术分析与私聊内容误发至公群。
- **长篇技术排版防暴投**：自动拦截超过 250 字且包含 Markdown 代码块（```` ``` ````）的硬核技术方案，早晚报/战报/科普正规播报享受正则豁免。

### 5. ✂️ 长文本智能断句分段 (Smart Split)
- 一次性长文本超过触发阈值（如 200~400 字）时，结合 Flash-Lite 模型或本地自然断句算法，在句号、感叹号、问号处优雅切分成多个连续气泡，配合 400ms 拟人延迟按序下发，彻底告别单条超长消息。

### 6. 🖼️ 180s 跨进程媒体去重 (Outbound Deduplication)
- 基于内容 MD5 哈希与内存/文件双层锁，严格拦截 180 秒内重复下发的相同文本与图片，杜绝脚本与主程序双发导致的复读。

### 7. 📊 可视化 Web 管理控制台 (Visual Web Dashboard)
- 零配置无缝嵌入 DeepSeek Harness 设置中心！
- 提供直观的 KPI 统计看板、实时缓冲池监控器、在线安全攻防测试工具与滚动运行日志流。

## 📦 安装与接入

### 1. 安装插件

在您的 DSH 运行环境中安装：

```bash
# 通过 npm / pnpm 安装
pnpm add dsh-qq-buffer

# 或克隆源码至 plugins 目录并安装依赖
git clone https://github.com/EmilVoid/dsh-qq-buffer.git
```

### 2. 在 profile 中注册插件

在 profile 的 `cordis.patch.yml` 中添加：

```yaml
- insert:
    - id: qq-buffer
      name: dsh-qq-buffer
      config:
        enabled: true
```

## ⚙️ 配置说明

插件支持通过 **DSH Web 设置界面（设置 -> 群聊智能缓冲）** 在线热调参，也可以直接编辑配置文件 `~/.dsh/profiles/web/qq_buffer_config.json`：

| 配置项 | 类型 | 默认值 | 作用说明 |
| :--- | :---: | :---: | :--- |
| `enabled` | `boolean` | `true` | 全局启用/关闭缓冲与拦截功能 |
| `idle_timeout_sec` | `number` | `8` | 普通群消息静默倒计时（秒），无新消息时触发派发 |
| `mention_wait_sec` | `number` | `5` | 收到 `@机器人` 后的快速缓冲收敛窗口（秒） |
| `max_wait_sec` | `number` | `30` | 缓冲区最大等待硬上限（秒），防止长消息持续无限等待 |
| `max_buffer_count` | `number` | `10` | 单次聚合的最大消息条数上限 |
| `active_context_sec` | `number` | `120` | 回复完成后开启的免艾特连续对话活跃期（秒） |
| `mention_keywords` | `string` | `哈基米,(@you)` | 触发主动响应的艾特或代称关键词（逗号分隔） |
| `block_tags` | `string` | `task ready,task completed...` | 物理阻断的系统违禁词黑名单（逗号分隔） |
| `smart_split_enabled` | `boolean` | `true` | 是否开启长输出自动断句分段下发 |
| `smart_split_trigger_chars` | `number` | `200` | 触发智能断句的字数阈值 |
| `smart_split_max_chars` | `number` | `300` | 智能断句单段最大字数上限 |
| `block_tool_errors` | `boolean` | `true` | 是否物理阻断中间工具报错流出至群聊 |
| `master_sender_id` | `string` | `""` | **主人专属 OpenID**（享受 100% 白名单特权通道） |
| `master_name` | `string` | `""` | **主人专属群昵称**（辅助识别白名单） |
| `security_guard_enabled` | `boolean` | `true` | 是否启用防提示词注入与越权攻击安全审查 |
| `security_alert_c2c` | `boolean` | `true` | 拦截非主人恶意攻击时是否向主人发送 C2C 私聊警报 |

## 🖥️ WebUI 管理控制台预览

启动 DeepSeek Harness 后，在浏览器中进入 **「设置」->「群聊智能缓冲」**：

1. **核心 KPI 看板**：实时展示累计入站消息数、缓冲合并批次、初筛通过/静默数、出站拦截数及安全攻击拦截数。
2. **实时缓冲池监控器**：实时呈现每个群聊的缓冲池队列、当前倒计时状态、活跃说话人及剩余活跃秒数。
3. **参数在线热调**：滑动微调防抖与断句参数，保存即刻热生效。
4. **安全防线在线演练**：提供提示词注入在线测试沙盒，可实时模拟攻击判定与私聊告警卡片预览。
5. **审计日志流**：支持实时刷新与清空运行日志。
